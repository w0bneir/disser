# Sequence-level Gate 0: подавление слышимой повторяемости

Дата фиксации протокола: 2026-08-28. Параметры фиксируются до первого
прослушивания.

## Вопрос

Могут ли почти незаметные изменения отдельных SFX уменьшить эффект «пулемёта»
при последовательном воспроизведении одного события, не разрушая его
идентичность и естественность?

## Гипотеза

Контекстно-зависимый выбор спектральных микровариаций одного референса даст менее
механическую последовательность, чем точное повторение и независимая
pitch/gain-рандомизация. Отдельные события при этом не обязаны восприниматься как
явно разные дубли.

## Материал

- один mono reference, полученный без изменения исходного WAV;
- 20 событий в каждой последовательности;
- одинаковое положение onset для всех методов;
- одинаковая интегральная RMS-громкость;
- один общий peak-safety scale для всех последовательностей;
- слепые обозначения X1–X4.

## Сравниваемые методы

1. точное повторение одного референса;
2. стандартная игровая pitch/gain-рандомизация;
3. последовательность из шести ранее полученных причинных микровариаций;
4. sequence-aware выбор из банка коротких velvet-noise spectral variations.

## Слуховые вопросы

Для каждой последовательности:

- механическая повторяемость: 1/5 — не слышна, 5/5 — очень сильная;
- идентичность исходного события: 1–5;
- естественность: 1–5;
- артефакты: нет / лёгкие / сильные;
- пригодность для игры: 1–5.

## Решение Gate 0

Маршрут проходит дальше, если хотя бы один исследуемый метод:

- уменьшает механическую повторяемость относительно точного повтора минимум на
  2 пункта;
- сохраняет идентичность не ниже 4/5;
- сохраняет естественность не ниже 4/5;
- не содержит сильных артефактов или дополнительных выстрелов;
- получает пригодность не ниже 3/5.

Если условия не выполнены, sequence-level маршрут останавливается. Подбор
параметров после раскрытия слепого теста в рамках этого Gate 0 запрещён.
