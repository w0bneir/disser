# Метод v2: структурно-управляемый ресинтез SFX

## Исследовательский вопрос

Можно ли по одному аудиореференсу получить серию новых дублей, которые
воспринимаются как то же событие, но не являются точными копиями?

## Гипотеза

Полная перегенерация события создаёт неустойчивую границу между копированием и
потерей идентичности. Более управляемый результат может дать раздельный
стохастический ресинтез перцептивно вариативных компонентов при сохранении
инвариантов события.

## Инварианты

- число и положение основных атак;
- общая длительность;
- макродинамическая огибающая;
- грубый спектральный силуэт;
- отсутствие новых событий.

## Вариативные компоненты

- межполосная микровременная структура атаки;
- локальный спектральный residual тела;
- фазовая структура и частотно-зависимое затухание хвоста.

Сигнал анализируется автоматически по RMS decay. Границы атаки и тела
определяются первыми устойчивыми пересечениями уровней −6 и −18 dB после
энергетического пика, с безопасными ограничениями для one-shot SFX.

## Gate 1

До прослушивания создаются ровно шесть причинных кандидатов:

1. две степени multiband micro-delay только в атаке;
2. две степени переноса спектрального residual только в теле;
3. две конфигурации all-pass decorrelation только в хвосте.

Кандидаты не комбинируются. Механизм проходит дальше, если хотя бы один файл
получает: идентичность ≥4/5, естественность ≥4/5, полезное отличие ≥3/5 и не
содержит дополнительных событий. Если ни один механизм не проходит, маршрут
останавливается без parameter sweep.
