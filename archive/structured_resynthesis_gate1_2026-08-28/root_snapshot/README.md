# Reference-Conditioned Structured SFX Resynthesis

Активный диссертационный черновик: автоматическое создание вариаций одного
one-shot SFX без текстового промпта и без полной нейросетевой перегенерации.

Метод разделяет событие на перцептивно разные области — атаку, тело и хвост — и
применяет к каждой области собственное ограниченное стохастическое
преобразование. Временной каркас, длительность и число событий сохраняются.

Первый этап — причинный Gate 1 на `references/shot_sound.wav`: по две изолированные
вариации атаки, тела и хвоста. Комбинирование и интерфейс запрещены, пока хотя бы
один механизм не пройдёт слуховую оценку.

Старые эксперименты заморожены в
`archive/neural_reference_variations_2026-08-28/`. Их тяжёлые результаты и веса
оставлены по стабильным путям `results/` и `artifacts/`.

## Запуск Gate 1

```bat
python run_structured_resynthesis_gate1.py --reference references\shot_sound.wav --results-dir results\YYYY-MM-DD_structured_shot_gate1
```

Метод работает на CPU и не загружает генеративные модели.
