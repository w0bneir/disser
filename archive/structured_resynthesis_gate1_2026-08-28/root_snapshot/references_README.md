# Референсы

- `shot_sound.wav` — основной one-shot для причинного Gate 1 нового метода;
- `metal_impact.wav` — второй тип события после успешного Gate 1;
- `wood_creak.wav` — более сложное протяжённое событие для проверки границ
  переносимости.

Файлы не модифицируются. Все результаты получают ту же частоту дискретизации,
длину и число каналов, что и соответствующий подготовленный mono reference.
