# Референсные WAV-файлы

- `shot_sound.wav` — одиночный выстрел с длинным естественным хвостом, основной
  короткий/транзиентный case;
- `wood_creak.wav` — протяжённый двухчастный скрип дерева.
- `metal_impact.wav` — сохранённый диагностический референс прежней серии; он
  исключён из основной проверки после аудита, обнаружившего жёсткий клиппинг
  примерно `14.8%` отсчётов и несоответствие prompt фактической структуре.

`shot_sound.wav` проверен перед включением в протокол: PCM 16-bit, `44 100 Гц`,
`1.714 с`, два идентичных mono-канала, практически без клиппинга. Резкая
широкополосная атака сочетается с хвостом примерно до `1.4 с` и вторичным
структурным всплеском около `0.75 с`.

Пути основной серии задаются в `../configs/reference_variations.json`, а DSP-
контроля — в `../configs/dsp_baseline.json`. Исходные файлы не изменяются во
время экспериментов; код сам приводит их к 44,1 кГц для Stable Audio и общей
оценки.

В основном сценарии prompt описывает то же семейство события, что и референс.
Замена материала допускается только в конфигурациях `../configs/stress_tests/`
и не используется как главное доказательство гипотезы.
