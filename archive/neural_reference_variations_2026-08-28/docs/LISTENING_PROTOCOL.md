# Пилотный протокол слепого прослушивания

## Назначение

Протокол `pilot_blind_listening_v1` проверяет вопрос, на который объективная
огибающая не отвечает: воспринимаются ли новые файлы как естественные дубли
того же конкретного события и полезнее ли их разнообразие обычной DSP-
обработки.

Пилот с одним опытным саунд-дизайнером используется для принятия инженерного
решения о следующем эксперименте. Он не считается итоговым статистическим
доказательством диссертации.

## Материал

Для одного референса и одинаковых seed формируются:

- шесть анонимных одиночных стимулов: три DSP v1 и три Reference SDEdit;
- три анонимных loop-пакета: Repeat, DSP v1 и Reference SDEdit;
- единый reference при 44,1 кГц;
- отдельный закрытый ключ рандомизации.

Text-only не включается в пилот: объективно он уже не сохраняет событие и не
является главным конкурентом проверяемой гипотезы.

## Индивидуальные оценки

Каждый стимул получает оценки от 1 до 5:

- идентичность конкретного события;
- естественность;
- выраженность артефактов (`1` — нет, `5` — сильные);
- полезность для саунд-дизайна.

## Оценка пакетов

Анонимные loop-последовательности оцениваются по:

- постоянству идентичности события;
- естественности;
- полезному разнообразию;
- артефактам;
- слуховому утомлению;
- практической полезности.

## Ограничение смещения

- ключ не открывается до сохранения обеих таблиц;
- во время теста не просматриваются waveform, графики и метрики;
- громкость фиксируется по reference;
- каждый файл прослушивается не более двух раз;
- randomization seed и хэши исходников сохраняются в закрытом context JSON.

## Решение после пилота

Если Reference SDEdit имеет приемлемую идентичность и превосходит DSP по
естественности или полезному разнообразию, метод переносится на новые
референсы. Если идентичность систематически низка, разрешается только заранее
ограниченная однофакторная абляция noise strength. Свободный перебор нескольких
параметров не проводится.

## Воспроизводимые команды

Сборка пакета:

```bat
python prepare_listening_test.py --case-id wood_creak --reference references\wood_creak.wav --generation-results-dir results\2026-08-19_wood_reference_sde_50step_01 --output-dir results\2026-08-22_wood_pilot_listening_v1 --seeds 17 42 2026 --randomization-seed 20260822 --loop-repetitions 3 --silence-seconds 0.25
```

После полного заполнения двух CSV:

```bat
python analyze_listening_test.py --listening-dir results\2026-08-22_wood_pilot_listening_v1
```

Анализатор откажется раскрывать ключ, пока отсутствует хотя бы одна оценка или
`listener_id`.
