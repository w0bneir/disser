# Референсные WAV-файлы

Поместите сюда два собственных WAV-файла и сохраните имена из `../experiments.json`:

- `metal_impact.wav` — короткий ударный звук;
- `wood_creak.wav` — более протяженный или затухающий звук.

Можно использовать другие имена и пути, но тогда обновите поле `reference_wav` в конфиге. Референс задает только временную огибающую; английский prompt должен описывать материал и характер генерируемого SFX.
