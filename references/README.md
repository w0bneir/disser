# Аудиоматериал

Исходные WAV никогда не изменяются на месте. Все выровненные клипы,
последовательности и отчёты создаются только под `results/`.

## Натуральный пул СКС

`group_1/` содержит 26 stereo PCM24/44.1 kHz записей, распределённых по шести
группам:

- группы 1–4: по пять файлов;
- группы 5–6: по три файла.

Со слов владельца, это живые записи одного СКС без намеренной обработки. Файлы
имеют Broadcast-WAV/REAPER provenance одного экспорта, поэтому в научном тексте
используется осторожная формулировка: **«натуральные записи, экспортированные из
REAPER без заявленной обработки»**, а не «неизменённые recorder masters».

До основного эксперимента необходимо документировать:

1. источник и право исследовательского использования/распространения;
2. помещение, дистанцию, микрофоны и тракт записи;
3. являются ли пары групп 1/2, 3/4 и 5/6 параллельными перспективами одних
   физических выстрелов;
4. применялись ли при экспорте gain, normalization, limiter или иной DSP.

Пока эти данные не установлены, группы используются как отдельные акустические
контексты и не смешиваются в один runtime-пул. Файлы с одинаковым индексом из
потенциально парных групп не считаются независимыми событиями.

## Исторические одиночные референсы

- `shot_sound.wav` — одиночный выстрел прежних reference-conditioned опытов;
- `metal_impact.wav` — короткий импакт;
- `wood_creak.wav` — протяжённый скрип дерева.

Они относятся к архивным направлениям и не входят в новый натуральный пул.
