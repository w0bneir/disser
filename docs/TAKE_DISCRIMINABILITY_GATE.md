# Gate различимости натуральных дублей

## Причина

В первом sequence-пилоте один слушатель с уверенностью 4/5 не услышал различий
ни в одной из четырёх пар, включая Repeat-one против Shuffle пяти натуральных
дублей. Поэтому результаты H1/H2 не интерпретируются: сначала необходимо
проверить чувствительность материала и процедуры.

## Дизайн

Gate использует одну операционально выделенную группу и не оптимизирует
scheduler. Все стимулы анонимизированы.

Одиночные пары:

1. идентичный medoid против его точной копии — контроль ложных срабатываний;
2. наиболее близкая пара по акустической дистанции v1;
3. пара около медианы расстояний;
4. наиболее далёкая пара.

Одиночные WAV сохраняют естественные относительные уровни. Применяются только
onset alignment/crop и один общий peak-safety scale.

Короткие циклы:

1. Repeat medoid против чередования наиболее далёкой пары;
2. Repeat medoid против Shuffle полного пула;
3. Shuffle с сохранённой динамикой против того же расписания после bounded
   clip-level early-RMS matching.

Все готовые циклы согласуются только по общей RMS и получают общий peak-safety
scale. Это сохраняет внутреннюю динамику raw-последовательностей и изолирует
влияние поклипового matching.

## Решение после прослушивания

- Если far/median пары не различаются, текущая группа непригодна для исследования
  слышимой антиповторяемости.
- Если одиночные дубли различаются, а Repeat/Shuffle — нет, проблема в длине,
  перекрытии хвостов или sequence-интерфейсе.
- Если raw Shuffle различим, а clip-matched нет, matching удаляет полезный
  источник вариативности и должен быть исключён или ослаблен.
- Только после успешного gate разрешается новый scheduler-пилот.
