# Состояние проекта на 2026-09-01

## Научное направление

Тема: **«Разработка метода перцептивно ограниченного синтеза вариаций звуковых
эффектов на основе статистики натуральных дублей»**.

Gate v0 показал, что гладкие macro-изменения EQ, огибающей и stereo width могут
стать слышимыми без артефактов, но не воспринимаются как полезный новый дубль.
Поэтому v1 проверяет новую гипотезу: полезная вариативность требует замены
микроструктуры тела/хвоста при неизменной идентифицирующей атаке.

## Что реализовано в v1

- CPU-only анализ всех 26 stereo/44.1 kHz натуральных записей;
- 90 признаков микроструктуры в трёх временных зонах;
- внутригрупповая нормализация шести групп `5+5+5+5+3+3`, без ложного
  объединения возможных микрофонных перспектив;
- 46 натуральных пар для калибровки коридора;
- новый стохастический носитель для каждого seed, сформированный спектральной
  огибающей референса;
- отдельный mid/side рендер;
- sample-exact сохранение первых 55 ms и плавный ввод изменения;
- автоматический поиск силы для натуральных Q25/median/Q75 с верхним пределом;
- слепой factorial gate и loop-сравнение;
- атомарная публикация результата, SHA-256 исходников/реализации/стимулов и
  технический audio gate.

## Что ещё не доказано

Объективное попадание в натуральный descriptor-коридор не означает, что звук
стал естественным или полезным. Основной результат текущего этапа определит
слепое прослушивание:

1. слышно ли micro-only отличие;
2. остаётся ли тот же выстрел;
3. является ли отличие полезным новым дублем;
4. возникают ли металлические/шумовые артефакты;
5. уменьшает ли пул разных seed «пулемётный эффект».

Если median/upper дают полезное отличие без артефактов, механизм v1 проходит
proof-of-mechanism. Если слышна только шумовая подмена или все дозы бесполезны,
гипотеза данного renderer отвергается без дальнейшего перебора силы.
