# Следующий шаг: локализация полезной вариативности в малой группе

## Решение и входные условия

Сохраняем работу внутри групп из **3–5 натуральных дублей одного события**.
Большой корпус и обучение большой нейросети для этого диагностического шага
не требуются. Для будущего рабочего прототипа предложен вход в виде малой
группы, с последующим расширением пула; окончательный режим входа обсуждается
с пользователем. Однореференсное обобщение этим опытом не проверяется.

Существенное условие — в группе должны быть хотя бы два дубля, различие которых
слушатель считает полезным при сохранении одного события. Пять почти одинаковых
записей не дают оснований обещать полезную новую вариативность. Если такого
контроля нет, сначала меняем пару или группу, сохраняя небольшой объём входа.

## Почему не продолжается подстройка noise-renderer v1

Аудит коммита `7d52959` выявил:

- protected 55 ms содержат 99.34% энергии reference;
- lower gain clamp создаёт шум даже при нулевом входе;
- PSD floor искажает тихие признаки и делает расстояние зависимым от уровня;
- объединённые квантили нескольких групп не задают допустимость для группы 1;
- расстояние после калибровки меняется при peak scaling;
- эксперт отметил отсутствие полезности и шум во всех micro-условиях.

Старые `microstructure_synthesis.py` и `run_microstructure_draft.py` сохранены
для воспроизводимости отрицательного результата. Их ошибки не объявляются
исправленными: текущий маршрут их **не использует**. Новые сравнения используют
натуральный сигнал без генерации шумового носителя и отдельный измеритель.

## Что реализовано

`natural_event_regions.py`:

- нормализация события перед измерением формы; отсутствие абсолютного PSD floor;
- 55 диагностических признаков распределения энергии, спектра и stereo;
- спектр по энергии каналов, без разрушительного mono-fold;
- отдельный профиль каждой группы; сторонние группы не меняют её результаты;
- отсутствие обратных MAD-весов и автоматического порога «естественности»;
- обмен ранней и поздней областями натуральной пары с одним stereo-mask;
- точное сохранение исходных отсчётов вне 6 ms crossfade;
- self-exchange возвращает исходник, zero-exchange возвращает ноль;
- измерения по фактическому экспортированному PCM.

Новый descriptor — **диагностика крупной формы события**. Он не объявляется
полной моделью микроструктуры или перцептивной близости. Выходы не оптимизируются
к значению этого расстояния.

`run_natural_region_gate.py`:

- отдельный новый пакет, отказ от перезаписи существующего;
- пять кодированных сравнений, общий reference, одиночные и парные серии;
- исходные различия уровня сохраняются, отдельно включён level-only контроль;
- один общий коэффициент peak safety для всех одиночных и последовательностей;
- PCM24 stereo/44.1 kHz на текущих данных;
- UUID пакета, хеши стимулов, A/B-назначения и session ID в выгружаемой анкете;
- проверка экспортированных WAV, HTML-инвентаря и хешей;
- хеши всех трёх используемых локальных модулей и версии runtime;
- строгая расшифровка и заранее заданное правило решения;
- автосохранение формы, проверка неполных ответов, остановка предыдущего плеера.

## Конкретная пара и дизайн

В оценке `perceptual_variation_analysis_v0_01` пара `SHOT 1.4 / SHOT 1.1`
была отмечена как слегка полезная, без артефактов. Это слабый положительный
контроль, поэтому в новом опыте полезность целого натурального дубля снова
проверяется. Выбор не основан на максимизации неисправной старой дистанции.

Пять условий, их коды скрыты от слушателя:

1. Целый натуральный donor.
2. Ранняя часть donor + последующая часть reference.
3. Ранняя часть reference + последующая часть donor.
4. Reference с одним коэффициентом усиления, соответствующим RMS donor.
5. Точная копия reference, прошедшая self-exchange.

Граница выбирается до оценок по минимуму совместной энергии в диапазоне
45–65 ms подготовленного клипа. В текущей паре она равна **64.966 ms**;
crossfade 6 ms. При pre-roll 20 ms это около 44.966 ms после обнаруженного
onset. Две составные записи сохраняют взаимодополняющие части исходной пары.
Это проверка вклада регионов, не обещание новых независимых натуральных дублей.

Для каждого условия доступны шесть событий: reference/variant чередуются с
интервалом 1.2 s. Сравнение — с шестью повторами reference. Коды условий
перемешаны, но reference всегда явно подписан. Это тест с замаскированными
условиями, не двойное слепое исследование.

## Как принимается решение

- Точная копия воспринимается иначе или имеет новые артефакты: опыт не даёт
  однозначного заключения; проверить условия сравнения.
- Целый natural donor неполезен: сменить пару/группу до следующего синтеза.
- Level-only полезен: громкость является возможным объяснением; прежде чем
  приписывать эффект структуре, нужен контроль уровня.
- Natural полезен, level-only нет, ранний перенос полезен без артефактов:
  ранняя область поддерживается как направление следующего метода.
- Аналогичный результат только для позднего переноса: исследовать позднюю
  область.
- Полезны оба: проверять совместные региональные изменения.
- Natural полезен, составные варианты нет: обмен регионами не поддерживается;
  возможна важность связи ранней и последующей частей или дефекты склейки.

Дополнительно фиксируется предпочтение серии. Даже удачная региональная
рекомбинация не доказывает расширение разнообразия сверх исходного пула:
вариант может звучать как один из его доноров. Следующий генеративный этап
обязан сравнивать выход со **всеми** исходниками группы, а не только с одним.

## Проверки и результат сборки

- Все 60 Python-тестов прошли, включая шесть новых содержательных проверок.
- На всех 26 реальных WAV изменение общего уровня на −40 dB меняет новый
  descriptor максимум на `3.33e-16`.
- Профиль группы 1 при анализе отдельно и вместе с другими группами совпадает
  точно.
- Пакет содержит 12 WAV; подтверждены форматы, peak, хеши и exact-copy контроль.
- Offline-проверка JavaScript проверила отказ при неполной анкете, восстановление
  ответов, обработчик переключения плееров и JSON с ID/хешами пакета.
- Реальная браузерная проверка не завершена: Browser URL policy заблокировала
  доступ к локальному file URL. Обход не предпринимался. Поддержка воспроизведения
  PCM24 в конкретном браузере пользователя остаётся непроверенной этим сеансом.

```text
results/2026-09-05_natural_region_gate_01/experiment/region_gate.html
```

Команды для воспроизведения и раскрытия:

```powershell
python -m unittest discover
python run_natural_region_gate.py --results-dir results\YYYY-MM-DD_natural_region_gate_01
node tools\check_region_form.cjs results\YYYY-MM-DD_natural_region_gate_01
python run_natural_region_gate.py --results-dir results\YYYY-MM-DD_natural_region_gate_01 --ratings C:\path\to\natural_region_ratings_ID.json
```

Декодирование создаёт отдельный файл с хешем анкеты в имени. Старые стимулы
и ответы не заменяются. Для следующей группы/пары задать `--group`,
`--reference`, `--donor` и новый каталог результатов.
